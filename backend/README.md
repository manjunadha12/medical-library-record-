# SecureMed Share API

See the [project README](../README.md) for configuration, service startup, and deployment. The Express server serves the built React application from the same origin as its API.

API groups include authentication (`/api/auth`), records (`/api/records`), consent (`/api/consent`), directory (`/api/doctors`), audit (`/api/audit`), notifications (`/api/notifications`), integrity (`/api/verify`), administration (`/api/admin`), and health (`/api/health`).
